
**[Sharing] Fix for npm / PyPI / NuGet Access Issues Caused by Global Secure Access**

Apologies for another post on package installation restrictions 😊.

Following the recent PyPI and NuGet-related updates,

I came across an additional workaround that may help others facing similar issues.

As a follow-up to the recent posts regarding blocked access to PyPI and NuGet package repositories,

I received additional guidance that may help others experiencing similar issues.

If commands such as npm install, pip install, dotnet restore, or similar package manager operations are being blocked by Global Secure Access, you can request access through the following Access Packages.

**NPM Access Package Long-Term**
[https://myaccess.microsoft.com/@microsoft.onmicrosoft.com#/access-packages/baf702e6-6ffc-4885-ac02-…](https://myaccess.microsoft.com/@microsoft.onmicrosoft.com#/access-packages/baf702e6-6ffc-4885-ac02-2463f4bbef38 "https://myaccess.microsoft.com/@microsoft.onmicrosoft.com#/access-packages/baf702e6-6ffc-4885-ac02-2463f4bbef38")

**PyPI Access Package Long-Term**
[https://myaccess.microsoft.com/@microsoft.onmicrosoft.com#/access-packages/636f5a58-c265-47b1-9833-…](https://myaccess.microsoft.com/@microsoft.onmicrosoft.com#/access-packages/636f5a58-c265-47b1-9833-c7195d9b8679 "https://myaccess.microsoft.com/@microsoft.onmicrosoft.com#/access-packages/636f5a58-c265-47b1-9833-c7195d9b8679")

**NuGet Access Package Long-Term**
[https://myaccess.microsoft.com/@microsoft.onmicrosoft.com#/access-packages/ee2749cd-1b76-468a-8f4a-…](https://myaccess.microsoft.com/@microsoft.onmicrosoft.com#/access-packages/ee2749cd-1b76-468a-8f4a-1248c8c35eac "https://myaccess.microsoft.com/@microsoft.onmicrosoft.com#/access-packages/ee2749cd-1b76-468a-8f4a-1248c8c35eac")

**Request Guidance**
• Select Option 1

• Provide a justification similar to:
"As a Microsoft Technical Trainer, I regularly deliver customer training, workshops, and demonstrations involving GitHub Copilot, AI Foundry, Azure, and developer tools. Access to approved public package repositories is required to install dependencies, validate lab environments, troubleshoot customer issues, and ensure successful delivery of hands-on training activities."

According to the guidance shared, once approved, this should help resolve package installation issues caused by Global Secure Access restrictions.

This may be particularly useful for those delivering customer demos, workshops, GitHub Copilot training, AI Foundry labs, hackathons, and other technical training activities that require package downloads during setup or labs.

Thanks to everyone who helped investigate and share the workaround.

Hopefully this helps others who encounter similar issues.
